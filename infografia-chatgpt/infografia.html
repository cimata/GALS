CHATGPT ENTERPRISE · GUÍA RÁPIDA

Prompt, skill y plugin, de un vistazo

Cada nivel contiene al anterior. Un plugin puede llevar skills dentro, y una skill es, en el fondo, un prompt guardado para reutilizarlo.

03

Plugin (complemento)

Paquete instalable que reúne skills y conexiones con otras herramientas. Permite a ChatGPT leer datos o actuar en servicios externos.

Se instala desde Plugins en la barra lateral, si el administrador lo ha habilitado. Después, @nombre, el botón + o ChatGPT lo usa solo cuando viene al caso.

02

Skill (habilidad)

Instrucciones guardadas para una tarea concreta, con sus pasos, criterios y archivos de apoyo. Se crea una vez y se reutiliza o se comparte con el equipo.

Escribe @ en el cuadro de mensaje y elige la skill. ChatGPT también puede activarla solo si la petición encaja con su descripción.

01

Prompt (instrucción)

Lo que escribes en el chat en cada momento. Sirve para esa conversación y no se guarda como herramienta.

Se escribe directamente en el cuadro de mensaje. No requiere configuración.

Fuente: OpenAI Help Center, «Skills in ChatGPT» y «Plugins in ChatGPT». Consultado el 23/10/2026. Los menús pueden variar según plan, rol y configuración del espacio de trabajo.

REGLA PRÁCTICA

Si escribes el mismo prompt por tercera vez, conviértelo en skill.

Si la tarea necesita datos de otra herramienta, busca un plugin.

Cuando una skill sea importante para el resultado, invócala con @ en lugar de confiar en que ChatGPT la elija solo. Si no encuentras un plugin, pide al administrador del espacio de trabajo que lo habilite.
